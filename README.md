## About the Course

This course introduces both classical and modern computer vision, including topics such as:

- Image formation, representation, and processing
- Filtering, convolution, and Fourier analysis
- Edge and feature detection
- Feature matching
- Camera geometry and calibration
- Stereo vision, motion, and 3D reconstruction
- Image classification and object detection
- Deep learning and convolutional neural networks
- Practical computer vision using Python, OpenCV, and PyTorch
